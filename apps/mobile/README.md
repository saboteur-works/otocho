# @otocho/mobile (stub)

Capacitor wrapper for Otocho (iOS / Android). **Not yet wired** — placeholder for
the phased scaffold.

When implemented, this target bundles the `@otocho/app` web build into native iOS
and Android shells, and provides the mobile implementation of the `@otocho/storage`
`StoragePort` backed by the Capacitor Filesystem plugin. Per spec FR-13, mobile is
read/search + light capture; structured authoring (preset chains) stays on desktop.
